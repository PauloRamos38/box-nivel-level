Modelo de caixas

Elemento box-level

Parágrafos e títulos são exemplos de elementos box-level. Eles ocupam, por padrão, toda a largura disponível e começam em uma nova linha.

Elemento inline-level

Links são exemplos de elementos inline-level: permanecem na mesma linha do texto. Este é um link para o Curso em Vídeo.

O modelo de caixas

Cada elemento pode ser entendido como uma caixa formada por content, padding, border e margin. Neste exemplo, as cores e bordas ajudam a visualizar essas propriedades.
